# OpenRepurpose

**Interns:** Beyza Yörük, Chin Hung Lin, Christina Fu
**Project Type:** Dossier Generator / Evidence Module

## Overview
OpenRepurpose is a shared intern project focused on building AI-driven dossier and evidence-generation workflows for drug repurposing and target validation. The project is split across three linked modules with a common cohort starter repo.

## Deliverables
- CLI dossier generator for gene, disease, or drug-target queries
- Shared starter repo with three sub-templates: dossier generator, dashboard, computation engine
- Evidence cards and mechanism reports with versioned Markdown output

## Core Tools
- Open Targets
- ChEMBL
- ClinVar
- Database-specific APIs (e.g., COSMIC, PharmGKB, OMIM, DisGeNET)

## Tech Stack
Python, `google-generativeai`, requests, pandas, matplotlib, CLI tooling

This README is a project frame for the cohort-level OpenRepurpose effort; interns can use it to onboard and assign work.
